# 只读案例展示

在仓库根目录运行 `python -m http.server 8081 --bind 127.0.0.1 --directory showcase`，打开 `http://127.0.0.1:8081`。

页面只加载同目录公开案例JSON，不连接任务API、不收密钥或源码、不执行代码。T1/T2/T3属于固定离线脚本案例，展示运行机制，不能作为真实模型修复成功率。案例对应代码身份记录为基线加未提交工作区；原始历史报告另存于backend/data，不混入公开样例。

另有四条标记为“历史真实模型记录”：T1一次修复产物通过但run预算暂停，以及T1/T2/T3各一次正常done/verified=true。三条成功记录的原测试和导出补丁均已独立核对，在新副本直接应用补丁后分别2、4、5项通过，没有手工补改。T2使用已有7B低内存CPU配置，T3使用代码3B；每条记录分别标明模型、源码摘要、用量和时间线，不能拼成同配置3/3或稳定成功率。

两个新增案例的`patch`直接来自脱敏导出，`provenance`保留各自run、配置与代码身份；案例页显示原样补丁，包括T2模型删掉的顶部任务说明，不另行美化为最小补丁。来源见[真实验收](../docs/local-acceptance-2026-10-20.md)，低内存运行方式见[操作指南](../docs/low-memory-local-model.md)。不公开完整数据库、原始prompt、宿主绝对路径或私有源码。

预算到限会暂停，操作者必须设置更大的有限上限才能续跑；未知模型用量、工具结果未知或工作区漂移时停止并保留现场。当前这些故障场景由临时数据自动化回归验证，可在docs/testing.md查阅证据。
