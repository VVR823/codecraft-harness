## 2. 关键偏差与教训

### 🔴 偏差 1：免费 LLM 能力边界（最大偏差，已转成亮点）
- 现象：`glm-4-flash`（旧）多轮上下文退化——连续 3 步写同一坏文件；`glm-4-flash-250414`（新免费）T1 稳、T2 六连败（JSON 裸参数丢 thought / 引号包 content / 重复 def 头，失败模式各不相同且重试救不回）。
- 处置：协议演进三板斧（edit_file 精准编辑 / 纠错教学 / LLM_RETRY 2→3）+ **A/B 换 glm-4-air 一次全绿**。
- 结论（面试口径）：**harness 架构正确性靠 A/B 验证，模型是独立变量**；免费模型写长代码 JSON 不稳是真实边界，不是代码 bug。此结论比"demo 能跑"更能体现工程判断力。

### 🔴 偏差 2：任务包设计会诱发 AI 特定错误
- T2 初版 module.py 有包装层（normalize 调 _zscore）：AI 用 write_file 整文件覆盖时**误删包装函数** → ImportError（免费/付费模型都可能犯）。
- 教训：待补函数放单函数文件；任务包本身要"对 AI 友好"，不能只对人工可读。
- T2 红绿数 3红1绿 → 改版全红 4（更贴"测试全红"设计），README/单测参数同步改。

### 偏差 3：成本比预期低一个量级
- 计划估 T1~T3 各 5~30k token。实测单次 5k~18k（air），run_all（3 任务×2 次）总计 ~60k token ≈ 0.1 元内。
- 预算校准基数：最大单次 18,147 ×1.5 ≈ 27k；config DEFAULT_TOKEN_BUDGET=60k 偏松，M2 激活护栏时收紧到 ~30k。
