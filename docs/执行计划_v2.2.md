## 0. 一句话定位

给一个自然语言工程目标，Agent 自主完成「规划 → 写码 → 跑测试 → 失败自修 → 全绿」的多轮长任务。轻量沙箱隔离、可中断续跑、可审计回放、成本有护栏。原创实现，DeerFlow / DeepSeek 公开架构 / MyCoder 只作架构参照。

## 1. 定位与叙事（grill Q1/Q2 定稿）

- **够用线 = 端到端 demo + 3 个硬数字**（不是走完全部里程碑、不是部署上线）。面试作品，不是产品。
- **双项目分工**：海龟汤=主作品（落地、真实数据），CodeCraft=第二作品（系统设计深度）。话术：海龟汤证明"会用 AI 做出能跑的东西"，CodeCraft 证明"能设计 AI 系统本身的工程骨架"。
- 时间预算：**每周 15~20h × 8 周 = 120~160h**。超时先砍 UI，保韧性主线。

## 3. MVP 底线（五条，证据可复现）

1. 单条长任务自修到绿 → 证据：pytest 退出码 0
2. 进程杀死可恢复（resume 不重放 done_actions）→ 证据：日志 + 录屏
3. 工作区漂移可识别（ws_hash 比对）→ 证据：检测日志命中 + 恢复后仍绿
4. 预算护栏触发过（超限→暂停→人工批准续跑）→ 证据：审批记录
5. T1~T3 全绿 + 预算内 → 证据：tasks/run_all.py 输出表（数字①）

## 5. 成本护栏（Day1 默认）

预算上限 + 超限暂停 + 仅人工批准续跑。默认预算由 T1~T3 各跑 2~3 次取 token 中位数 ×1.5 校准。记账字段 tokens_used 每步累计。

## 6. 回归任务集（T1~T3 手写，内容即考卷）

- T1 入门·单测修复：1 个函数边界条件错，1 测试红（5~10k token）
- T2 简单·补缺失函数：模块引用被清空的函数，测试全红（10~20k）
- T3 中等·跨文件 suite 红：一处逻辑 bug 致 3 测试红，原因跨 2 文件（15~30k）

每条 = module.py（埋 bug）+ test_module.py（验收）+ README.md（目标描述）。要求：bug 手动埋、**作者先人工确认能修**、git 提交作还原点。T4~T6 作储备不承诺。
